---------------------------------------------
2. PROPRIEDADES DA SOMA E DA SUBTRAÇÃO
---------------------------------------------
Explica como a soma e a subtração podem ser reorganizadas ou desfeitas.

01 Comutativa:
    a + b = b + a

02 Associativa:
    (a + b) + c = a + (b + c)

03 Elemento neutro:
    a + 0 = a

04 Oposto:
    a + (-a) = 0

05 Subtração como soma do oposto:
    a - b = a + (-b)

---------------------------------------------
3. PROPRIEDADES DA MULTIPLICAÇÃO E DA DIVISÃO
---------------------------------------------
Explica como produtos e divisões são organizados e simplificados.

01 Comutativa:
    a * b = b * a

02 Associativa:
    (a * b) * c = a * (b * c)

03 Distributiva:
    a * (b + c) = a*b + a*c
    a * (b - c) = a*b - a*c

04 Elemento neutro:
    a * 1 = a

05 Elemento nulo:
    a * 0 = 0

06 Exemplo de aplicação:
    3*(x + 2) = 3x + 6

5. PRODUTOS NOTÁVEIS
---------------------------------------------
Apresenta identidades que facilitam o desenvolvimento de produtos algébricos.

    (a + b)² = a² + 2ab + b²

03 Produto da soma pela diferença:
    (a + b)(a - b) = a² - b²

---------------------------------------------
6. FATORAÇÃO
---------------------------------------------
Explica como transformar uma soma ou diferença em uma multiplicação de fatores.

01 Fator comum:
    ax + ay = a(x + y)

02 Diferença de quadrados:
    a² - b² = (a - b)(a + b)

03 Fatoração por agrupamento:
    ax + ay + bx + by
    = a(x + y) + b(x + y)
    = (a + b)(x + y)

---------------------------------------------
7. POTÊNCIAS
---------------------------------------------
Apresenta as regras para operar bases e expoentes.

01 Produto de potências de mesma base:
    a^m * a^n = a^(m+n)

02 Quociente de potências de mesma base:
    a^m / a^n = a^(m-n), com a diferente de 0

03 Potência de potência:
    (a^m)^n = a^(m*n)

04 Potência de um produto:
    (ab)^n = a^n*b^n

05 Potência de um quociente:
    (a/b)^n = a^n/b^n, com b diferente de 0

06 Expoente zero:
    a^0 = 1, com a diferente de 0

07 Expoente negativo:
    a^(-n) = 1/a^n

08 Expoente fracionário:
    a^(1/n) = raiz_n(a)
    a^(m/n) = raiz_n(a^m)

08 Exemplo de expoente fracionário:
    x^(2/3) = raiz_cubica(x²)

---------------------------------------------
8. RAÍZES
---------------------------------------------
Explica o significado das raízes e sua relação com os expoentes fracionários.

01 Conversão entre raízes e potências:
    raiz(a) = a^(1/2)
    raiz_cubica(a) = a^(1/3)

02 Produto de raízes:
    raiz(a)*raiz(b) = raiz(ab)

03 Quociente de raízes:
    raiz(a)/raiz(b) = raiz(a/b), quando b não é zero

---------------------------------------------
9. FRAÇÕES
---------------------------------------------
Ensina como manter denominadores, fazer operações e simplificar frações.

01 Frações equivalentes:
    a/b = (a*k)/(b*k), com k diferente de 0

02 Simplificação:
    (a*k)/(b*k) = a/b

03 Soma com denominadores iguais:
    a/c + b/c = (a + b)/c

04 Subtração com denominadores iguais:
    a/c - b/c = (a - b)/c

05 Soma com denominadores diferentes:
    a/b + c/d = (a*d + c*b)/(b*d)

06 Subtração com denominadores diferentes:
    a/b - c/d = (a*d - c*b)/(b*d)

07 Multiplicação:
    (a/b)*(c/d) = (a*c)/(b*d)

08 Divisão:
    (a/b)/(c/d) = (a/b)*(d/c) = (a*d)/(b*c)

08 Regra importante:
    dividir por uma fração é multiplicar pelo seu inverso.

08 Exemplo:
    1/(2/3) = 1*(3/2) = 3/2

---------------------------------------------
10. FRAÇÕES ANINHADAS
---------------------------------------------
Mostra como resolver frações que aparecem dentro de outras frações.

01 Simplificação de uma fração interna:

    1/(1 + 1/(x + 1))

01 Primeiro simplifique o denominador:

    1 + 1/(x + 1)
    = (x + 1)/(x + 1) + 1/(x + 1)
    = (x + 2)/(x + 1)

02 Depois use o inverso:

    1/((x + 2)/(x + 1))
    = (x + 1)/(x + 2)

02 Para a questão:

    1/(1 + 1/(1 + 1/(x + 1)))

01 A fração mais interna fica:

    1 + 1/(x + 1) = (x + 2)/(x + 1)

02 Então:

    1/(1 + (x + 1)/(x + 2))
    = 1/((2x + 3)/(x + 2))
    = (x + 2)/(2x + 3)

13. FUNÇÕES E COMPOSIÇÃO
---------------------------------------------
Ensina os fundamentos e o funcionamento de funções e de funções dentro de funções.

01 Uma função associa uma entrada a uma saída:
    f(x) = x² + 1

02 Composição:
    (f o g)(x) = f(g(x))

02 Exemplo:
    f(u) = sin(u)
    g(x) = x²
    f(g(x)) = sin(x²)

03 Essa estrutura aparece na regra da cadeia:
    (f(g(x)))' = f'(g(x))*g'(x)

14. LOGARITMOS
---------------------------------------------
Explica como os logaritmos desfazem potências e transformam operações.

01 Definição:
    log_a(b) = c  se, e somente se, a^c = b

02 Produto:
    log_a(x*y) = log_a(x) + log_a(y)

03 Quociente:
    log_a(x/y) = log_a(x) - log_a(y)

04 Potência:
    log_a(x^r) = r*log_a(x)

05 Logaritmo natural:
    ln(x) = log_e(x)

15. REGRAS USADAS COMO BASE PARA DERIVADAS
---------------------------------------------
Reúne as regras algébricas e de derivação que serão usadas no Cálculo 1.

01 Soma:
    (u + v)' = u' + v'

02 Subtração:
    (u - v)' = u' - v'

03 Produto:
    (u*v)' = u'*v + u*v'

04 Quociente:
    (u/v)' = (u'*v - u*v')/v²

05 Potência:
    (u^n)' = n*u^(n-1)*u'

06 Regra da cadeia:
    (f(g(x)))' = f'(g(x))*g'(x)

---------------------------------------------
16. ROTEIRO PARA SIMPLIFICAR UMA EXPRESSÃO
---------------------------------------------
Mostra uma sequência prática para organizar uma expressão antes de derivá-la.

01 Resolva primeiro parênteses, potências e raízes.
02 Procure denominadores comuns nas frações.
03 Transforme divisão por fração em multiplicação pelo inverso.
04 Distribua fatores quando necessário.
05 Reduza termos semelhantes.
06 Cancele apenas fatores iguais em numerador e denominador.
07 Só depois aplique as regras de derivação.

Observação:
Nunca se deve cancelar termos que estão somando ou subtraindo. O
cancelamento é feito entre fatores multiplicando o numerador e o denominador.
