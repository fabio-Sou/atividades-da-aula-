# Atividades da aula

Este repositório reúne atividades, anotações e projetos desenvolvidos durante
aulas e estudos de programação e matemática. Há exercícios em notebooks,
programas em Python, materiais de revisão e pequenos projetos web.

## Organização

- **Atividade-Avaliativa/** — guias de estudo, atividades dos módulos,
  anotações e resumos.

- **deverdomodulo/** e **deverslide/** — exercícios e trabalhos organizados
  em notebooks.

- **Calculadoras/** — projetos de calculadora básica e calculadora científica
  com interface gráfica.

- **derivada/** — materiais e ferramentas de estudo sobre derivadas.

- **Pratica/** — página web feita com HTML, CSS e JavaScript.

- **painel_s1_windows/** — projeto independente em Python; consulte o README
  da pasta para instruções próprias.

Também há arquivos de estudo e notebooks diretamente na pasta principal.
Consulte o README de cada projeto para saber como executá-lo.
