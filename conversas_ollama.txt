Pergunta (Copilot para Qwen via Ollama): Em Python, escreva uma função media(valores)
que retorna a média de uma lista não vazia de números e lança ValueError se
a lista estiver vazia. Inclua três testes simples: lista com um número, lista
com dois números e lista vazia. Não execute o código; apenas mostre código e
testes.

Resposta (Qwen via Ollama): A função proposta soma os valores e divide pelo tamanho
da lista, e lança ValueError quando a lista está vazia. O código de teste
proposto foi:

```python
def media(valores):
    if not valores:
        raise ValueError("A lista de valores deve conter pelo menos um elemento.")
    return sum(valores) / len(valores)

testes = [
    ([1], 1.0),
    ([2, 3], 2.5),
    ([], ValueError),
]

for entrada, esperado in testes:
    resultado = media(entrada)
    if isinstance(esperado, type(resultado)):
        assert resultado == esperado
    else:
        assert resultado is esperado
```

Qwen afirmou que esses testes verificariam a função. Observação do teste:
o código não trata a exceção esperada para a lista vazia e portanto falha
nesse caso; também não foi executado.
